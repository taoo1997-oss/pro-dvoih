# Скрипты канала @sait_vmesto_otkrytki

## Первый запуск (один раз)

```
cd "для телеграм/скрипты"
npm install
```

Ставится `puppeteer-core` (браузер не качает — использует установленный Edge).

## shot.js — пересобрать скриншоты работ

Проходит все `portfolio/NN-*/index.html`, кладёт по 6 картинок в
`для телеграм/скрины/<работа>/` (обложка, приглашение, дата+отсчёт, программа,
галерея, дресс-код).

```
node shot.js
```

Нужен Edge по пути `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`
или свой браузер через `set BROWSER=путь\к\chrome.exe`.

## post.js — опубликовать в канал

Токен бота — в `token.txt` рядом (уже лежит). Канал `@sait_vmesto_otkrytki`,
контакт `@fuchiji_k` — в начале файла.

```
node post.js --dry        превью, ничего не отправляет
node post.js --pinned     только закреп (пост + закрепить)
node post.js --no-pinned  только работы
node post.js              закреп + 14 работ
```

Порядок публикации и тексты подписей — массивы `ORDER` и `W` в начале файла.
Добавил новую работу: впиши её в `W` и `ORDER`, прогони `shot.js`, потом
`node post.js --no-pinned` (или закомментируй в `ORDER` уже опубликованные).
