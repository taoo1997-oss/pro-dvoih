# Свадебные лендинги — рабочая папка студии

Здесь всё для изготовления свадебных сайтов-приглашений: бриф в двух форматах,
семь шаблонов лендинга (три базовых + четыре по референсам), генератор
портфолио и 14 готовых работ.

Основные папки проекта — заглавными, чтобы сразу цеплялись взглядом:
`БРИФ/`, `САЙТ/` (витрина), `ПОРТФОЛИО/` (работы), `ТЕЛЕГА/` (материалы канала),
`ПАРНЕРЫ/`. Служебное — строчными: `shablon/`, `materialy/`, `тест/`, `шрифты/`,
`референсы/`. Скрипты сборки уже знают эти имена.

## Бриф

- **Клиенту удобнее форма** → Google Документ:
  https://docs.google.com/document/d/14wz6pbi9HEfStmSiuf0GUHp8MFJS1psKzA54O1SyKGM/edit
  Читать как есть или за 15 минут собрать по нему Google Форму — у каждого вопроса
  помечен тип поля.
- **Веб-версия** → `БРИФ/brief.html` (публикуется артефактом Claude). Ответы —
  на `БРИФ/brief-otvety.html`.
- Исходник обоих — `БРИФ/brief-google-doc.md`.
- **Раздел 3 «Стиль и визуал»** клиент проходит не открывая портфолио:
  прямо в форме — превью 7 вариантов компоновки (каждая картинка = чекбокс) и
  10 палитр кружочками (как дресс-код в лендинге). Собирается `brief_styles.py`
  (превью — из `БРИФ/styli/`, палитры — из `concepts.py`). После смены шаблонов
  или палитр: обновить скриншот в `БРИФ/styli/<буква>.jpg` и прогнать
  `python materialy/build/brief_styles.py`.

## Как собрать новый лендинг

1. Добавьте концепцию в `materialy/build/concepts.py` (поля описаны в шапке файла),
   в т.ч. `template` = `"A"`…`"G"` и 4 id фото Unsplash («до свадьбы», не съёмка дня).
2. `python materialy/build/fetch_images.py` — скачает и пережмёт фото, положит
   `images.json` в `materialy/foto-ishodniki/<slug>/`. (Или вручную положите
   `hero.jpg` + `g1/g2/g3.jpg` и соберите `images.json` = `{role: "data:image/jpeg;base64,…"}`.)
3. `python materialy/build/build.py` — соберёт `ПОРТФОЛИО/<NN Имена>/index.html`
   и `spisok-gostey.html`, обновит витрину и `ПОРТФОЛИО/_meta.json`.
4. Опубликуйте `index.html` артефактом Claude → ссылка паре.
   `spisok-gostey.html` — отдельным артефактом, ссылка только для пары.
   RSVP и список гостей общаются через `window.storage`, ключ `guest_list_<slug>`.

Сборка идемпотентна.

### RSVP

Форма: имя + сколько угодно полей «кто ещё придёт с вами» (одно уже открыто,
кнопка «+ добавить ещё гостя» добавляет строки — семью вписывает один человек) +
короткое поле для пожеланий. Кнопки «Приду / Не смогу» нет: кто не идёт — просто
не отправляет форму. Отправка = «придём». Запись: `{name, guests:[...], note, ts}`.
Приватный `spisok-gostey.html` считает «человек придёт» (имя + гости) и «заявок».

## Бумажное приглашение и комплект для гостей — платные допы

На выдаче, помимо ссылки, можно отдать паре:

- **Бумажное приглашение A5 — +1 500 ₽.** Двусторонний макет под типографию:
  лицо — фото из шапки лендинга (`intro_lead`, как на сайте, только текста меньше),
  оборот — что, где и когда. Блока «добавить гостей» и формы на бумаге нет.
  `python materialy/build/build_priglashenie.py` собирает
  `ПОРТФОЛИО/<NN Имена>/для печати/index.html` из той же концепции, что и лендинг
  (палитра, фото и данные всегда совпадают).
- **Комплект для гостей без интернета.** Экраны лендинга картинками + собранный
  из них же PDF (страница = экран, без искажений) — переслать в мессенджере или
  распечатать тем, кому неудобно открывать ссылку.

PDF-ы (бумажное приглашение и комплект для гостей) делает
`ТЕЛЕГА/скрипты/pack.js` через headless-Edge:

```
python materialy/build/build_priglashenie.py     # HTML-макеты A5 для всех 14
cd "ТЕЛЕГА/скрипты" && node pack.js               # PDF + картинки; node pack.js 03 — одна пара
```

Итог на пару: `ПОРТФОЛИО/<NN Имена>/для печати/priglashenie-A5.pdf`,
`ПОРТФОЛИО/<NN Имена>/пдф и пнг версии/приглашение.pdf` и `.../пдф и пнг версии/экраны/*.png`.
Печать приглашения: браузер → «Печать» → A5, двусторонняя (переворот по длинному краю), поля 0.

## Технические заметки

- Лендинги и бриф рассчитаны на публикацию **артефактами Claude**: RSVP, списки
  гостей и приём брифа работают через `window.storage` (как в исходном проекте
  «Константин и Юлия»). Открытые просто файлом — формы покажут мягкую ошибку.
- Внешние ресурсы только со шрифтовых CDN Google. Фото вшиты как `data:`-URI →
  файлы 400–800 КБ, это норма (лимит артефакта 16 МБ).
- Шрифты берут кириллические подмножества Google Fonts.
