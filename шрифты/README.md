# Ваши шрифты

Две папки — сюда кладёте файлы шрифтов, которые вам нравятся.

```
шрифты/
  имена/            — каллиграфия/скрипт для имён на обложке (как Saint Amour Script)
  основной-текст/    — что-то читаемое для абзацев, дат, подписей
```

## Что класть

- **Формат:** лучше всего `.woff2`. Подойдут и `.ttf` / `.otf` — я сконвертирую
  или встрою как есть.
- **Кириллица обязательна.** Если в шрифте нет русских букв — он не подойдёт,
  имена и текст будут набираться запасным шрифтом.
- Можно несколько вариантов в каждую папку — я покажу их все в брифе, вы выберете.
- Если у шрифта несколько начертаний (Regular, Medium, Bold) — кладите нужные,
  для основного текста удобно иметь Regular + Bold.
- Имя файла роли не играет, но по нему я подпишу образец — называйте понятно,
  например `Kudryashev-Display.otf`, `Golos-Text-Regular.woff2`.

## Как отдать результат

1. Скидываете файлы в папки.
2. Пишете мне «готово».
3. Я:
   - проверю, что в каждом шрифте есть кириллица;
   - соберу в бриф (`brief/brief.html` и Google Документ) блок «Как будут
     выглядеть шрифты» — образцы имён (Имя мужчины и Имя женщины) и абзац
     основного текста каждым шрифтом, чтобы клиент сразу видел;
   - при желании подключу понравившийся шрифт в шаблоны портфолио вместо
     нынешних (Great Vibes / Cormorant / Forum / Tenor Sans).

## Лицензия

Кладите только шрифты, которые вам можно использовать в коммерческих проектах
(куплены, бесплатны для коммерции или свободная лицензия SIL OFL). Для встраивания
в веб-страницу подходит большинство настольных лицензий, но лучше проверьте
условия конкретного шрифта.
